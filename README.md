# Ecommerce Customer Behaviour Report


A comprehensive, interactive report analyzing customer behaviour for an ecommerce platform. Built with Jekyll and Just the Docs, this site presents data-driven insights, machine learning results, and actionable business recommendations.

## Live Website

[E-Commerce Report](https://choupinghu.github.io/ecommerce-report/)

## Features
- Data cleaning and preprocessing walkthrough
- Supervised learning (classification, evaluation, business interpretation)
- Unsupervised learning (clustering, association rules)
- Business insights and recommendations
- Clean, responsive documentation site

---

Built with [Jekyll](https://jekyllrb.com/) & [Just the Docs](https://just-the-docs.com/).
